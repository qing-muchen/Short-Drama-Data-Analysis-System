# 短剧数据管理与分析系统用户操作手册

## 1. 手册说明

本手册适用于短剧数据管理与分析系统 V1.0 的验收演示和日常使用。页面按钮会根据用户角色和数据状态显示；若当前环境没有对应业务数据，页面将显示空状态或明确的 Availability，而不会自动生成示例结果。

## 2. 用户角色

| 角色 | 使用范围 |
| --- | --- |
| 管理员（ADMINISTRATOR） | 数据维护、导入、分析计算、异常和行动管理，以及全部查询功能 |
| 普通用户（USER） | Dashboard、列表查询、分析查看、治理查看和报告导出 |

系统不开放自助注册。账号由系统部署或管理员流程预先配置。

## 3. 用户登录

### 3.1 登录步骤

1. 使用浏览器打开系统地址；
2. 系统未登录时自动进入登录页；
3. 在“用户名”输入框输入系统账号；
4. 在“密码”输入框输入密码；
5. 单击“登录”；
6. 登录成功后进入 Dashboard 数据驾驶舱。

若用户名、密码或用户状态无效，页面显示登录失败信息。请确认账号由系统管理员创建且状态为 ACTIVE。

### 3.2 会话与权限

登录后的业务请求自动携带访问令牌。访问没有权限的操作时，系统返回权限错误；令牌失效或当前用户校验失败时，需要重新登录。

## 4. Dashboard 首页

### 4.1 查看系统概览

Dashboard 默认展示：

- 短剧、演员、导演、公司、平台数量；
- 总播放量、平均互动率和质量问题数；
- Heat、Growth、Potential 排行；
- 近 30 日运营趋势；
- 数据质量摘要；
- 热门标签分布。

单击“刷新数据”可重新请求 Dashboard 数据。不同区域独立加载，部分区域失败时页面会保留其他已加载内容。

### 4.2 进入功能模块

页面顶部提供短剧管理、演员管理、平台管理、标签管理、分析中心、综合评分、数据质量治理、播放趋势预测、异常检测、运营行动、运营分析、数据治理、分析报告等入口。管理员还能看到数据导入入口。

## 5. 基础数据查询与维护

### 5.1 短剧列表

1. 在 Dashboard 单击“短剧管理”；
2. 使用名称、状态或标签等条件筛选；
3. 查看分页列表；
4. 选择目标短剧进入详情。

管理员可使用页面提供的维护操作新增、修改或停用数据；普通用户仅执行授权查询。删除类操作通常表现为停用或受业务约束保护，操作前应核对目标记录。

### 5.2 演员、平台与标签

从 Dashboard 进入对应管理页面后，可执行列表查询、筛选和详情查看。管理员可在页面实际提供的操作范围内维护资料。关系数据仍由系统约束保护，不能使用自由文本代替已定义关系。

## 6. 数据导入

该功能主要供管理员使用。

### 6.1 上传文件

1. 在 Dashboard 单击“数据导入”；
2. 选择页面支持的导入类型；
3. 选择 CSV 或 XLSX 文件；
4. 提交文件并等待校验；
5. 查看导入任务状态。

### 6.2 查看错误并确认

1. 打开导入任务详情；
2. 若存在错误，进入错误列表查看行号、字段和错误原因；
3. 修正原始文件后重新上传；
4. 当校验结果符合要求时执行确认导入。

系统不会自动修改上传文件中的错误值。不要重复确认已经完成或状态不允许确认的任务。

## 7. 基础分析模块

### 7.1 综合评分

1. 从 Dashboard 进入“综合评分”；
2. 选择评分日期或页面提供的筛选条件；
3. 查看评分排行和等级分布；
4. 选择短剧查看评分维度、总分、等级、算法版本和分析时间；
5. 管理员可按页面提供的操作触发评分计算。

页面只展示服务端评分结果，不在浏览器中重算分数。

### 7.2 数据质量评分

1. 进入“数据质量治理”分析页面；
2. 查看当前质量总分、质量等级和各维度结果；
3. 查看历史质量结果和规则信息；
4. 管理员可触发授权范围内的质量计算。

本页面是持久化质量评分模块，不等同于第 11 节的数据治理中心。

### 7.3 播放趋势预测

1. 进入“播放趋势预测”；
2. 选择目标短剧；
3. 查看最新预测、目标日期和算法版本；
4. 查看该短剧的历史预测；
5. 管理员可在数据满足要求时触发预测计算。

若历史数据不足，系统会显示未生成或历史不足状态，不会以零值伪造预测。

### 7.4 异常检测

1. 进入“异常检测分析”；
2. 查看异常统计；
3. 按指标、异常类型、严重程度或状态筛选；
4. 查看异常记录、偏差和证据摘要；
5. 管理员可更新异常状态或触发检测。

## 8. 运营行动中心

1. 从 Dashboard 进入“运营行动中心”；
2. 查看行动统计和行动列表；
3. 按页面条件筛选行动；
4. 打开行动查看来源、负责人、状态和历史；
5. 授权用户执行分派、状态更新或添加处理评论；
6. 完成处理后核对行动历史是否完整。

运营行动记录用于跟踪执行过程，不代表行动与业务指标之间已经建立因果关系。

## 9. Drama Profile 使用

### 9.1 操作路径

```text
Dashboard
    ↓
短剧管理 / Drama 360° 全景画像入口
    ↓
选择短剧
    ↓
进入 /dramas/{id}/profile
    ↓
查看画像
```

### 9.2 查看画像

画像页面依次展示：

- Drama Header；
- Performance；
- Quality；
- Trend；
- Risk；
- Operations；
- Explanations。

每个卡片显示该模块的 Availability。`INSUFFICIENT_HISTORY` 表示历史不足，`NO_ANOMALY` 表示已检查但当前无异常，`NOT_DETECTED` 表示尚未检测，`NOT_AVAILABLE` 表示模块暂不可用。

单个卡片不可用不会阻断其他画像内容。页面中的详情入口仅负责导航，不复制对应模块的计算逻辑。

## 10. Operation Analytics 使用

### 10.1 进入页面

从 Dashboard 单击“运营分析中心”，进入 `/operation-analytics`。

### 10.2 Action Effect

1. 进入行动效果区域；
2. 使用页面提供的时间、行动或分页条件查询；
3. 查看行动完成时间前后窗口；
4. 查看指标值、变化方向、Availability 和非因果声明。

结果只表示行动发生前后观察到的变化，不表示行动导致变化。

### 10.3 Lifecycle

1. 在生命周期区域输入或选择 Drama ID；
2. 发起查询；
3. 查看 LAUNCH、GROWTH、STABLE、DECLINE 或 ARCHIVED；
4. 核对规则版本、分析时间和证据。

### 10.4 Benchmark

1. 在 Benchmark 区域填写平台和页面要求的 2–20 个 Drama ID；
2. 发起查询；
3. 查看滚动 30 日窗口、成员指标和组统计；
4. 核对 Availability。

Benchmark 不提供排名、最佳短剧或运营推荐。

## 11. Data Governance 使用

### 11.1 查看治理概览

1. 从 Dashboard 进入“数据治理中心”；
2. 查看 SYSTEM scope、总体 Availability 和 `analysis_as_of`；
3. 查看 Freshness、Completeness、Consistency 三张状态卡。

### 11.2 查看 Evidence

1. 在目标状态卡中单击 Evidence 查看入口；
2. 在 Evidence Drawer 中查看类型、消息、来源和 metadata；
3. 使用分页操作继续查看其他 Evidence；
4. 关闭 Drawer 返回概览。

页面仅展示后端结果。延迟、覆盖率和一致性状态均不在前端重新计算，也不会提供自动修复按钮。

## 12. Reports 使用

### 12.1 操作路径

```text
Dashboard
    ↓
分析报告中心
    ↓
选择报告
    ↓
配置 Filter
    ↓
查看 Preview
    ↓
确认 Export
    ↓
浏览器下载
```

### 12.2 选择报告

1. 进入 `/reports`；
2. 等待 Report Catalog 加载；
3. 从 Catalog 选择一个报告；
4. 核对报告说明、Schema Version、支持格式和 Snapshot Semantics。

报告目录由服务器返回，前端不维护另一份固定清单。

### 12.3 配置 Filter 与 Snapshot

1. 根据页面显示的 Filter Definition 输入条件；
2. ENUM Filter 从允许值中选择；
3. DATETIME 和可选 `analysis_as_of` 使用带时区的 ISO 8601 时间；
4. 设置 1–100 的预览行数；
5. 单击“查看预览”。

不填写 `analysis_as_of` 时由后端统一生成请求截点，前端不会自行填入当前时间。

### 12.4 查看 Preview

Preview 区域展示：

- Availability、Reasons 和 Message；
- `analysis_as_of`、timezone 和 semantics；
- 总行数、Schema Version 和来源版本；
- 按 Schema 顺序排列的表格列和数据。

`EMPTY` 表示查询成功但无匹配数据；`INSUFFICIENT` 表示数据不足；`NOT_AVAILABLE` 表示来源或流程不可用。

### 12.5 导出和下载

1. 在 Preview 结果中选择 CSV 或 XLSX；
2. 单击“确认导出”；
3. 核对 Report Type、格式、确认行数和数据截点；
4. 单击“确认并下载”；
5. 若服务器提示数据行数已变化，核对新行数并再次确认；
6. 浏览器开始下载后查看成功状态。

导出失败不会清空 Catalog 或 Preview。前端只接收 Blob，不解析或重新生成报告文件。

## 13. 常见状态与处理

| 状态或现象 | 含义与处理 |
| --- | --- |
| 401 Unauthorized | 登录状态无效，重新登录 |
| 403 Forbidden | 当前角色无操作权限，使用授权账号或联系管理员 |
| 页面无数据 | 检查筛选条件和源数据；查看 Availability，不将空状态视为系统故障 |
| INSUFFICIENT / INSUFFICIENT_HISTORY | 历史窗口不足，待数据积累后重试 |
| NOT_AVAILABLE | 来源或模块不可用，根据 Message/Reason 检查环境和数据 |
| 导出要求再次确认 | Preview 后数据行数变化或策略要求确认，核对服务器行数后再次确认 |
| 导出超限 | 缩小 Filter 范围；V1 不提供后台大文件任务 |

## 14. 使用注意事项

- 不要共享账号、密码或访问令牌；
- 管理员执行数据修改、导入确认和状态更新前应核对目标；
- 时间参数应使用带时区的 ISO 8601 格式；
- 分析结果应结合算法版本、规则版本、数据截点和 Availability 阅读；
- Action Effect 不能作为因果证明；
- Benchmark 不能作为最佳短剧或投资推荐；
- Evidence 是质量判断依据，不是自动修复方案；
- 下载文件可能包含业务数据，应按组织的数据安全要求保存和传递。
