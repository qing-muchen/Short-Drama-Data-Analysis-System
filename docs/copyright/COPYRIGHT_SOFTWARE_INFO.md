## 4. 软件定位

短剧数据管理与分析系统是一套面向短剧数据管理、数据分析、运营复盘、数据治理及报告输出的 Web 应用。

系统以短剧基础资料、平台关系、历史运营指标和已有分析结果为数据基础，支持：

- 短剧及相关主数据维护；
- CSV/XLSX 数据导入、校验和错误查看；
- 指标、评分、数据质量、预测和异常分析；
- 运营行动记录与行动前后指标变化复盘；
- Drama 360° 综合画像；
- Freshness、Completeness、Consistency 数据治理检查；
- 报告目录、预览以及 CSV/XLSX 导出。

主要使用对象包括短剧运营人员、数据管理人员、业务分析人员、系统管理员和验收人员。

## 5. 产品边界

V1.0 不包含：

- LLM、AI Agent 或生成式 AI；
- 推荐算法或推荐系统；
- 自动运营决策；
- 自动数据修复；
- 机器学习分类平台；
- 运营行动因果推断；
- 异步大规模报告任务；
- 报告文件长期持久化或下载审计表。

Operation Analytics 只描述运营行动前后观察到的指标变化，不表述“行动导致变化”。Reporting Center 只读取和输出已有数据事实，不重新计算评分、预测、异常或治理结果。
